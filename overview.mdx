## AI agents that speak, act and solve

Vitos is an end-to-end AI agent platform that lets you build, deploy, and manage intelligent agents — from voice bots that handle live customer calls to workflow orchestrators that coordinate complex business processes behind the scenes.

## How It All Fits Together

<Steps>
  <Step title="Choose your agent type">
    Pick the agent that matches your use case — Conversation for customer-facing interactions, Work for backend automation, Co-Pilot for API-first integration, or AOP to orchestrate all of them.
  </Step>
  <Step title="Configure and train">
    Set up your LLM provider, write or generate prompts, attach knowledge bases, and connect functions. Each agent type has its own configuration tailored to its purpose.
  </Step>
  <Step title="Test before you ship">
    Use the built-in Test tab or Prompt Playground to simulate conversations, catch edge cases, and optimize responses before going live.
  </Step>
  <Step title="Deploy and monitor">
    Deploy to your chosen channel — phone, WhatsApp, web, or API — and monitor live performance from the dashboard.
  </Step>
</Steps>

## Platform Sections

<AccordionGroup>
  <Accordion title="Build" icon="hammer">
    Create and configure your agents and workflows.

    - **AI Agents** — Conversation Agent (Single and Multi-Agent), Work Agent, Co-Pilot Agent
    - **Agent Operating Procedures (AOP)** — Orchestration workflows with schema-driven entities
    - **Integrations** — Connect external APIs and services
  </Accordion>

  <Accordion title="Resources" icon="database">
    Manage shared assets used across your agents.

    - **Knowledge Base** — Upload documents and URLs for AI-powered retrieval
    - **Channels** — Configure call providers (Twilio, Exotel, Ozonetel), SIP, social media, and web
    - **Providers** — Add and manage LLM, Transcriber, Voice, and Agent Platform credentials
    - **Schema** — Define entity tables and operation data tables that drive AOP workflows
  </Accordion>

  <Accordion title="Operate" icon="gauge-high">
    Monitor and manage live agents.

    - **Live** — Real-time call monitoring and agent status
    - **Tools** — Create and manage cloud functions used by your agents
  </Accordion>
</AccordionGroup>
